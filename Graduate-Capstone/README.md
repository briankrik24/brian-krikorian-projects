# Graduate Capstone: Machine Learning Address Validation

## Overview

This graduate capstone project explores the use of machine learning to validate and classify address records at scale. The goal was to improve data quality by identifying invalid or inconsistent address information and supporting automated validation workflows.

## Objectives

* Develop a machine learning model to classify address validity.
* Analyze millions of address records efficiently.
* Compare model performance using appropriate evaluation metrics.
* Demonstrate how machine learning can improve enterprise data quality processes.

## Technologies

* Python
* Scikit-learn
* Pandas
* NumPy
* Jupyter Notebook

## Results

The project demonstrates an end-to-end machine learning workflow including data preparation, feature engineering, model training, evaluation, and interpretation of results.
