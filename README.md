# Featured Project

## 🎮 Steam Analytics Platform

An end-to-end analytics engineering project that transforms nearly **90,000 Steam games** into an analytics-ready dataset using a Medallion Architecture (Bronze → Silver → Gold), DuckDB, SQL, and an interactive three-page Power BI dashboard.

Highlights include:

- ETL pipeline built with Python and Pandas
- Medallion Architecture (Bronze → Silver → Gold)
- Automated data profiling and validation
- DuckDB analytics layer
- Interactive Power BI dashboard
- DAX measures, Power Query transformations, and star schema modeling
- Revenue estimation and business insight dashboards

**Tools & Skills**

Python • Pandas • DuckDB • SQL • Power BI • Power Query • DAX • Data Modeling • ETL • Git
