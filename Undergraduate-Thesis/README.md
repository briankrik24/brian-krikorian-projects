# Undergraduate Thesis: NBA Player Value Analysis

## Overview

This undergraduate thesis applies statistical analysis and predictive modeling to evaluate NBA player value using historical performance data. The project investigates which player characteristics contribute most to overall value and explores how analytics can support player evaluation.

## Objectives

* Analyze NBA player performance data.
* Identify statistical drivers of player value.
* Build predictive models using historical data.
* Communicate findings through data visualization and statistical analysis.

## Technologies

* R
* Python
* Statistical Modeling
* Data Visualization

## Results

The project demonstrates the complete analytics process from data collection and cleaning through exploratory analysis, model development, and presentation of findings.
